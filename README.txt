DAILY WORD - SMART BIBLE APP STARTER

Included:
- Daily verse rotates by local date (7 sample entries)
- Sinhala meaning and English meaning
- Related verse references with Sinhala summaries
- Share verse (native share where available; copy fallback)
- Favorites stored in the browser
- Personal reflection saved locally on this device
- PWA manifest and offline service worker starter

Important:
- English Bible text is KJV (public domain).
- Sinhala scripture wording is a meaning-based rendering for this starter, not an official Sinhala Bible translation.
- Reflections and favorites are saved only in the current browser/device.
- Service worker requires HTTPS or localhost to install/work as a PWA.

Run locally:
1. Open a terminal in this folder.
2. Run: python -m http.server 8000
3. Open: http://localhost:8000

To publish free:
Upload the files to a GitHub repository and enable GitHub Pages (Settings > Pages > Deploy from branch).
